Нижняя шторка с секциями

Свайп вверх по кадру поднимает шторку, свайп вниз опускает. У шторки три уровня: скрыта, быстрые кнопки, полный список. Макет живой: свайпай мышью или пальцем по экрану телефона, нажимай кнопки, меняй значения.

Жесты

ДействиеЧто происходит
Свайп вверхСкрыта → быстрые кнопки → полный список
Свайп внизПолный список → быстрые кнопки → скрыта. Если внутри списка свайпнуть вниз, он сначала прокручивается до начала, и только потом сворачивается шторка.
Тап по ручкеТо же, что свайп вверх. С полного списка возвращает к быстрым кнопкам.
Тап по группеИз быстрых кнопок сразу открывает полный список на этой группе.
Тап по кадруФокус, как сейчас. Если открыт полный список, он сворачивается до быстрых кнопок.
Ручная панельВидна, пока шторка скрыта. Когда шторка поднимается, панель прячется, как и сейчас при открытых настройках.

Что исправлено

Раскрытый лист закрывает большую часть кадраИсправлено. Высота полного списка ограничена 66% видоискателя, верхняя треть кадра всегда видна. Быстрые кнопки в полном виде убраны, потому что дублируют секции, а список прокручивается внутри. Фон стал прозрачнее. Добавлен уровень «скрыта», где от шторки остаётся только ручка.
Свайп вверх конфликтует с ручной панельюЭто была моя ошибка. Ручная панель и так видна всегда: Swipe.init() включает её сразу, стрелка open_close_manual скрыта в разметке (visibility="gone"), а SwipeUp() только показывает уже видимую панель. Конфликта нет, свайп вверх целиком отдаётся шторке.
Текст не влезает и обрезается многоточиемИсправлено. Обрезанного текста в шторке больше нет. Быстрые кнопки показывают только иконку текущего значения, подпись остаётся лишь там, где иконка не скажет значение (R+J, 12). Сводки групп и заголовки секций показывают иконки изменённых параметров вместо перечисления значений. У вспышки, таймера и сетки варианты в переключателе тоже иконки, у остальных короткие подписи: 1×, 12, 16, 20, 2×. Значение справа от названия убрано, его видно по выбранному сегменту, полное название открывается подсказкой по долгому нажатию.
Список быстрых кнопок задан жёсткоИсправлено. У каждой настройки в полном списке есть булавка. Она добавляет настройку в быстрые кнопки, их максимум четыре, при переполнении вытесняется самая старая.
Свайп вниз открывает листИсправлено. Теперь всё наоборот, как ты просил: вверх поднимает, вниз опускает. Верхняя шторка убрана совсем, поэтому верхняя панель больше не прячется.

План по коду

  1. camera_fragment.xml: вместо верхнего settings_bar добавить CoordinatorLayout над layout_bottombar, внутри SettingsBarLayout с BottomSheetBehavior: hideable=true, peek = быстрые кнопки + группы, setMaxHeight = 66% видоискателя.
  2. CameraFragmentViewModel: вместо settingsBarVisible состояние из трёх значений: скрыта, быстрые, полный. manual_mode виден только в состоянии «скрыта», layout_topbar больше не прячется.
  3. Swipe.java: SwipeUp() поднимает шторку на уровень, SwipeDown() опускает. Из SwipeUp() убираются вызовы ManualModeConsole и анимация ocManual. onSingleTapUp сворачивает полный список до быстрых кнопок, вместо того чтобы закрывать шторку.
  4. SettingsBarEntryModel: поле группы (Съёмка, Формат, Вид). SettingsBarButtonModel: короткая подпись для всех пунктов, getTextLabel() уже есть.
  5. SettingsBarEntryView: ряд ImageButton заменить на MaterialButtonToggleGroup, слева от названия иконка параметра, справа булавка. Для вспышки и таймера иконки вариантов уже есть (ic_torch, ic_flash_off, ic_timeroff, ic_timer3s, ic_timer10s). Для сетки сейчас у всех вариантов одна ic_grid_on, нужны отдельные иконки для 3×3, 4×4, золотого сечения и диагонали.
  6. SettingsBarLayout: ручка, ряд быстрых кнопок, ячейки групп со сводкой, секции-аккордеон. Список быстрых кнопок сохраняется в PreferenceKeys.
