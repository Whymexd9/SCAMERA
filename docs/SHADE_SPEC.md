# Задача: нижняя шторка быстрых настроек (концепт E)

Макет: `shade-sheet.html` (открыть в браузере, он интерактивный). Заменить текущую верхнюю шторку `SettingsBarLayout` на нижний лист с секциями. Камеру, сессию, AE и обработку не трогать — изменение только UI.

## Поведение

Три состояния: `HIDDEN` → `PEEK` → `FULL`.

| Действие | Результат |
|---|---|
| Свайп вверх по видоискателю | на уровень выше (HIDDEN→PEEK→FULL) |
| Свайп вниз по видоискателю | на уровень ниже (FULL→PEEK→HIDDEN) |
| Свайп вниз внутри списка FULL | сначала прокрутка до начала, затем PEEK |
| Тап по ручке | HIDDEN/PEEK → FULL, FULL → PEEK |
| Тап по ячейке группы в PEEK | FULL с раскрытой этой группой |
| Тап по видоискателю | фокус как сейчас; если FULL → PEEK |

Ручная панель `manual_mode` видна только в `HIDDEN`. `layout_topbar` больше не скрывается.

## Вид

- Лист стоит над `layout_bottombar`, переключатель режимов и спуск не перекрываются.
- Фон как `vf_settings_background`, но с прозрачностью ~0.88, скругление 22dp только сверху.
- HIDDEN: видна только ручка (36×4dp).
- PEEK (~120dp): ручка; ряд быстрых кнопок; ряд из 3 ячеек групп.
  - Быстрые кнопки: круг 42dp с иконкой **текущего значения**, без названия. Подпись под кругом только если иконка не передаёт значение (R+J, 12). Изменённая от дефолта — белый круг, тёмная иконка. Тап — следующее значение. Максимум 4, ширина каждой = 1/4 ряда, при 1–3 кнопках **центрируются** (`LinearLayout`, `gravity=center_horizontal`).
  - Ячейка группы: название группы капсом + иконки изменённых параметров акцентом (до 4, дальше «+N», если нет — «—»).
- FULL: высота не больше 66% видоискателя, быстрые кнопки скрыты, аккордеон из групп (открыта одна), список прокручивается.
  - Заголовок группы: шеврон, название, иконки изменённых параметров.
  - Строка: иконка параметра, название (переносится, не обрезается), булавка справа; ниже сегментированный переключатель на всю ширину.
  - Сегменты: у вспышки, таймера, сетки — иконки; у остальных короткие подписи. Полное название — в tooltip / contentDescription.
  - Булавка добавляет/убирает параметр из быстрых кнопок; при 5-м вытесняется самый старый.
- Никакого текста с многоточием.

## Группы и короткие подписи

- Съёмка: Вспышка (Фонарик / Выкл), Таймер (Выкл / 3 с / 10 с), Брекетинг (Выкл / Норм. / Высок.), Замер AE (Выкл / Центр / Сред. / Точка), Частота кадров (Авто / 24 / 30 / 60), Стабилизация (Выкл / Вкл)
- Формат: RAW (JPEG / R+J / RAW), Сверхвысокое разрешение (Выкл / Вкл), Разрешение (1× / 12 / 16 / 20 / 2×), Даунсемплер (Lanc / Bicub / Area / Bilin)
- Вид: Сетка (Выкл / 3×3 / 4×4 / Φ / Диаг.), Энергосбережение (Выкл / Вкл)

Быстрые кнопки по умолчанию: Вспышка, Таймер, RAW, Сетка.

## План по коду

1. `camera_fragment.xml`: убрать верхний `settings_bar`; добавить `CoordinatorLayout` над `layout_bottombar`, внутри `SettingsBarLayout` с `BottomSheetBehavior` (`hideable=true`, peekHeight = быстрые кнопки + группы, `setMaxHeight` = 66% видоискателя). Material 1.13.0 уже подключён.
2. `CameraFragmentViewModel`: `settingsBarVisible` → состояние HIDDEN/PEEK/FULL; биндинги `manual_mode` и `layout_topbar` перевести на него.
3. `control/Swipe.java`: `SwipeUp()` — уровень выше, `SwipeDown()` — уровень ниже; убрать из `SwipeUp()` вызовы `ManualModeConsole` и анимацию `ocManual`; `onSingleTapUp` — FULL→PEEK вместо скрытия.
4. `SettingsBarEntryModel`: поле группы. `SettingsBarButtonModel`: короткая подпись и иконка варианта для всех пунктов (`getTextLabel()` уже есть).
5. `SettingsBarEntryView`: `MaterialButtonToggleGroup` вместо ряда `ImageButton`; иконка параметра слева, булавка справа.
6. `SettingsBarLayout`: ручка, ряд быстрых кнопок, ячейки групп, аккордеон.
7. `PreferenceKeys`: список быстрых кнопок (строка id через запятую).
8. Иконки: для вспышки и таймера есть (`ic_torch`, `ic_flash_off`, `ic_timeroff`, `ic_timer3s`, `ic_timer10s`). Для сетки у всех вариантов одна `ic_grid_on` — нужны 3×3, 4×4, золотое сечение, диагональ. Для иконок параметров без своих drawable — новые vector drawable 24dp, линия 1.8dp.

## Проверка

- Все 12 настроек меняются из FULL, значения сохраняются как сейчас (`SettingsBarEntryProvider.updateAllEntries`).
- Свайпы по таблице выше; свайп вниз внутри прокрученного списка сначала прокручивает.
- При 1, 2, 3 закреплённых кнопках ряд по центру.
- Ни одной надписи с многоточием на экране 360dp шириной.
