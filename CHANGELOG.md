# Изменения SCAMERA

## 2026-10-17 (вечер) — исправления

- 50 Мп через ZSL снова снимаются: досъём кадров после нажатия больше не упирается в ошибку «requires 1..64 past N and 0..8
  bracket requests».
- X200 Ultra: убран лишний модуль «2×» на полосе объективов (дубль встроенного 2× ISZ основной камеры).

## 2026-10-17 — сетка мозаики, FULLRES на OPPO, 50 Мп через ZSL

- Сетка на ISZ и FULLRES: новая поправка чувствительности пикселей Quad/Tetra (работает и в темноте), плавные веса кадров
  вместо ступенек 4×4, ядро склейки Quad днём 1,0 вместо 0,7 — диагональная штриховка на ткани и буквах примерно вдвое слабее.
- 50 Мп: склеиваются все снятые кадры (раньше память обрезала серию до 2 кадров); кадры берутся из ZSL-кольца до нажатия,
  недостающие и короткие кадры для светов — сразу после нажатия. 200 Мп снимаются, как раньше, после нажатия.
- 50 Мп: ультракороткий кадр для светов — пересветы больше не розовые; кадр, испорченный мерцанием ламп, выравнивается по
  полосам строк или отбрасывается (нет цветных полос на лампах).
- Видоискатель FULLRES 50 Мп снова идёт с частотой камеры (было ~11 к/с).
- OPPO Find X7 Ultra и другие OPPO на Snapdragon: FULLRES 50 Мп без аппаратного ремозаика (режим берётся из таблицы сенсора
  телефона и проверяется по кадрам), свои экспозиция и баланс белого, доступ к телевикам.
- «Мозаика без ремозаика»: новый первый пункт «Наш ремозаик» — можно снимать мозаику без нашего ремозаика.
- X100 Ultra / X300 Ultra: переключатель «FULLRES: аппаратный ремозаик» (основная камера 50 Мп).
- Настройки: группа «Настройки по модулям» (модули и их FULLRES 50 / 200 Мп), число кадров для 50 и 200 Мп, при включении
  «Свои настройки для каждого модуля» модули получают текущие настройки, а не значения по умолчанию.
- Файлы приложения перенесены из Android/data в Download/SCAMERA; в «Диагностике» — «Сохранять RAW-серию».
- Галерея: в информации о фото фактическое разрешение и модель телефона; в сравнении масштаб начинается с 0 %.
- Убран звуковой сигнал после спуска затвора.
